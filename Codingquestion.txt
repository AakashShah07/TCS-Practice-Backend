Q1   Given a string S consisting only of '*' and '#'.

Find the minimum number required to make the string valid.

A string is considered valid if the number of '*' and '#' are equal.

Rules
If count of '*' > count of '#' → return a positive integer
If count of '#' > count of '*' → return a negative integer
If both are equal → return 0
Example 1

Input:

###***

Output:

0

Explanation:
Number of '*' and '#' are equal.

Example 2

Input:

****##

Output:

2

Explanation:
There are 2 more '*' than '#'.




Q2. Given an integer array Arr of size N, find the count of elements whose value is greater than all of its previous elements.

Note
The first element is always counted.
An element is counted if it is strictly greater than every element before it.
Example
Input
N = 5
Arr = [7, 4, 8, 2, 9]
Explanation
7 → first element → counted
4 → not greater than 7
8 → greater than 7 and 4 → counted
2 → not greater than previous maximum
9 → greater than all previous elements → counted
Output
3



q3  At a fun fair, a street vendor is selling balloons of different colours.

He sells N balloons, where each balloon colour is stored in an array B[].

The task is to find the colour of the balloon that appears an odd number of times in the array.

Note
If more than one colour appears an odd number of times, print the first colour in the array whose count is odd.
Balloon colours may be in uppercase or lowercase.
If all colours appear an even number of times, print:
All are even
Example 1
Input
N = 7

B = [r, g, b, b, g, y, y]
Explanation

Counts:

r → 1 time
g → 2 times
b → 2 times
y → 2 times

Only r appears odd number of times.

Output
r
