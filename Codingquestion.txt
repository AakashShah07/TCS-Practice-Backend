Q1   Given a string S consisting only of '*' and '#'.

Find the minimum number required to make the string valid.

A string is considered valid if the number of '*' and '#' are equal.

Rules
If count of '*' > count of '#' → return a positive integer
If count of '#' > count of '*' → return a negative integer
If both are equal → return 0
Example 1

Input:

###***

Output:

0

Explanation:
Number of '*' and '#' are equal.

Example 2

Input:

****##

Output:

2

Explanation:
There are 2 more '*' than '#'.




Q2. Given an integer array Arr of size N, find the count of elements whose value is greater than all of its previous elements.

Note
The first element is always counted.
An element is counted if it is strictly greater than every element before it.
Example
Input
N = 5
Arr = [7, 4, 8, 2, 9]
Explanation
7 → first element → counted
4 → not greater than 7
8 → greater than 7 and 4 → counted
2 → not greater than previous maximum
9 → greater than all previous elements → counted

3

Q8:  Simple Question Statement

A mall parking lot is represented using a matrix of size R × C.

0 means the parking space is empty.
1 means the parking space is occupied.

Your task is to find the row that contains the maximum number of occupied parking spaces (1s).

If rows are counted starting from 1, return the row number having the highest count of 1s.

Approach

We will go row by row and count how many 1s are present in each row.

While traversing:

Keep track of:
maximum count of 1s found so far
row index where this maximum occurs

Whenever a row has more 1s than the current maximum:

update the maximum count
update the answer row

At the end, return the row number.

Logic
Steps
Read matrix dimensions R and C
Traverse every row
Count number of 1s in that row
Compare with current maximum
Store row index if current row has more 1s
Print the row number
